# Практична робота №2: ітератори та генератори

П'ять окремих програм демонструють протокол ітерації, ітерабельні контейнери, генераторні функції, потокову обробку даних і різницю між списковими та генераторними виразами.

## Запуск

Потрібен Python 3.10 або новіший. Зовнішні пакети не потрібні.

```bash
python practical_02_task_1_1.py
python practical_02_task_1_2.py
python practical_02_task_2_1.py
python practical_02_task_2_2.py
python practical_02_task_3_1.py
```

## Зміст

| Файл | Тема |
| --- | --- |
| `practical_02_task_1_1.py` | Ітератор `CyclicRange`, повтори, кроки й `StopIteration` |
| `practical_02_task_1_2.py` | Повторно ітерований `StudentGroup` із незалежними ітераторами |
| `practical_02_task_2_1.py` | Арифметична й геометрична прогресії, Фібоначчі, Коллатц, `flatten` |
| `practical_02_task_2_2.py` | Лінивий конвеєр генераторів для текстових оцінок |
| `practical_02_task_3_1.py` | Вимірювання пам'яті й часу для списків та генераторів |

`practical_02_task_3_1.py` створює `benchmark_results.csv`. Приклади запусків збережені у `console_output.txt` та `result_task_*.png`; повні лістинги, таблиця порівняння та висновки є у [PDF-звіті](report.pdf).
